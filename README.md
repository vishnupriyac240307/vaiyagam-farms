# வையகம் Farms (Vaiyagam Farms)

Premium, modern, responsive website for **வையகம் Farms**, a farm-direct agricultural products business based in Tamil Nadu, India.

---

## 🌾 Overview

வையகம் Farms bridges local agricultural growers and conscious households by sourcing quality agricultural produce directly from Tamil Nadu farmers:

- **Fresh Vegetables (புதிய காய்கறிகள்)**: Farm-fresh seasonal vegetables, tomatoes, carrots, beans, and greens sourced directly from farmers.
- **Fresh Coconuts (பச்சை & முற்றிய தேங்காய்)**: Natural quality whole and husked coconuts for daily household and bulk requirements.
- **Coconut Oil (தரமான தேங்காய் எண்ணெய்)**: Pure, dependable everyday essential.

## 🚢 Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys to **GitHub Pages** whenever changes are pushed to the `main` branch.

To enable GitHub Pages in your repository:
1. Go to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Every push to `main` will automatically build and publish the live site.
